Buat NODE Sambungan Jalur NODE
▸ TITIK NODE = satu titik sambungan ke 4 jalur berikut:
NODE ───► ADS1115 A0
NODE ───► R 470kΩ → ESP32 GND
NODE ───► R 10kΩ → Katoda 1N4148 → Anoda 1N4148 → ESP32 G32
NODE ───► C 100nF → ESP32 GND
NODE ───► — (kosong)
ℹ R 470kΩ = voltage divider / pull-down. R 10kΩ + 1N4148 = clamping diode ke G32 untuk proteksi over-voltage. C 100nF = filter noise.
